Security Write-ups

Cybersecurity analysis and technical documentation demonstrating communication of complex security concepts.

back2basics — Binary Exploitation

Pwn / Stack Overflow + ROP

Multi-stage ROP exploit leveraging a stack buffer overflow (0x100 bytes into a 0x40 buffer, return address at offset 72) to pivot execution into .bss, leak libc via puts(puts@got), and achieve code execution through system("cat flag.txt").

Kali Linux amd64 NX enabled No PIE No canary Partial RELRO

Technique

  1. Overflow saved return address at offset 72 via pop rbp ; ret gadget
  2. Return to 0x401221 (mid-function read(0, rbp-0x40, 0x100)) to get a second write primitive into arbitrary writable memory
  3. First pivot into .bss: call puts(puts@got) to leak libc, return to back2basics for another round
  4. Second pivot into a different .bss region (avoids overwriting the live frame)
  5. Leaked puts low bits match Ubuntu 24.04 glibc 2.39 (puts @ 0x87be0)
  6. Final payload: system = libc_base + 0x58750 with "cat flag.txt" in .bss

Deja Vu — ret2win

Pwn / Stack Overflow

Classic ret2win challenge. main calls gets(local_48) with no bounds checking. Overflow the buffer by 0x48 bytes to overwrite the return address and redirect execution to the win function that prints the flag.

Kali Linux amd64 NX enabled No PIE No canary Partial RELRO SHSTK IBT

Technique

  1. main @ 0x4012ec calls gets(local_48) — unbounded input
  2. win @ 0x4011f6 prints the flag
  3. Payload: "A" * 0x48 + p64(win+5) — the +5 skips the push rbp to fix stack alignment
Flag: squ1rrel{w3v3_b33n_h3r3_b3f0r3_n0w_0nt0_b1gger_4nd_better}
